## 적용 시점/트리거
공사 중 발생하는 폐기물과 공사 완료 후 철거물·잔재물을 반출할 때 적용합니다.

---

## 전제조건
- 공사 신청 승인서 수령 완료

---

## 필요 입력물
- [ ] 폐기물 수거 용기 (마대, 톤백 등 — 공사업자 준비)
- [ ] 건설폐기물 처리 계획서 (대량 발생 시 관리사무소 제출)

---

## 절차

1. **분리배출**: 폐기물을 아래 분류 기준에 따라 현장에서 분리합니다
2. **용기 적재**: 지정 용기(마대, 톤백 등)에 담아 밀봉합니다
3. **지정 장소 보관**: 반출 전까지 아래 지정 장소에만 보관합니다
4. **반출 신청**: 대형 폐기물 반출 시 관리사무소에 반출 일정 신고
5. **반출**: 화물승강기 예약 후 지정 시간에 반출합니다
6. **적법 처리 확인**: 건설폐기물은 적법한 수거 업체를 통해 처리하고 처리 확인서 보관

---

## 폐기물 분류 기준

| 폐기물 종류 | 처리 방법 | 비고 |
|-------------|-----------|------|
| 목재·합판 | 지정 마대에 담아 반출 | 건설 폐목재 |
| 콘크리트·벽돌 조각 | 별도 용기에 담아 반출 | 혼합 금지 |
| 금속류 (철근, 파이프) | 별도 용기에 담아 반출 | |
| 단열재·스티로폼 | 압축 후 지정 용기 반출 | 비산 주의 |
| 도료·화학물질 용기 | 지정 폐액 수거 용기 | 일반 쓰레기 혼합 금지 |
| 일반 생활 쓰레기 | 건물 일반 쓰레기 규정 준수 | 건설 폐기물과 혼합 금지 |
| 석면 함유 자재 | 석면 해체 전문 업체 의뢰 필수 | 법적 규제 대상 |

## 폐기물 임시 보관 장소

- **지정 보관 구역**: [미결 — 예: B1 창고 또는 공사 구역 내]
- **보관 금지 장소**: 공용 복도, 비상구, 계단, 승강기 홀, 주차 구역
- **최대 보관 기간**: [미결 — N일] 이내 반출 완료 필수

- **지정 보관 구역**: B1 창고 또는 현장 지정 자재 보관 구역
- **보관 금지 장소**: 공용 복도, 비상구, 계단, 승강기 홀, 주차 구역
- **최대 보관 기간**: 7일 이내 반출 완료 필수

## 금지 행위

- 건물 쓰레기 분리수거함에 건설 폐기물 투기
- 배수구에 시멘트·도료 등 화학물질 세척 금지
- 공용 구역에 폐기물 방치
