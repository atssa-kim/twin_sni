## 위반 유형별 제재 기준

| 위반 유형 | 위반 규정 | 제재 내용 | 집행 주체 |
|-----------|-----------|-----------|-----------|
| 미승인 공사 시작 | 공사 신청 승인 전 착공 금지 | 즉시 공사 중지 명령 + 경위서 제출 후 재승인 필요 | 관리사무소 |
| 승인 범위 초과 공사 | 승인된 공사 범위 준수 의무 | 초과 부분 즉시 중지, 추가 승인 필요 | 관리사무소 |
| 미등록 인원 출입 | 인원 사전 등록 의무 | 경고 1회 → 재발 시 해당 인원 출입 금지 | 관리사무소 / 보안 |
| 안전 장비 미착용 | 전 인원 안전 장비 착용 의무 | 즉시 작업 중지, 착용 후 재개. 반복 시 경고 누적 | 관리사무소 |
| 소음·진동 기준 초과 | 허용 시간·기준 준수 의무 | 경고 1회 → 재발 시 당일 공사 중지 | 관리사무소 |
| 허용 시간 외 공사 | 공사 허용 시간 준수 의무 | 즉시 중지 + 경위서 제출 | 관리사무소 |
| 위험 작업 무신고 | 위험 작업 사전 신고 의무 | 즉시 중지 + 경위서 제출 + 사전 신고 후 재개 | 관리사무소 |
| 보양 미설치 | 의무 보양 구역 보양 의무 | 공사 중지, 보양 설치 확인 후 재개 | 관리사무소 |
| 공용 구역 방치 | 공용 구역 자재·폐기물 방치 금지 | 즉시 이동 명령, 반복 시 처리 비용 청구 | 관리사무소 |
| 불법 폐기물 투기 | 지정 장소 외 폐기물 투기 금지 | 청소 비용 청구 + 경고 | 관리사무소 |
| 시설물 파손 미신고 | 파손 즉시 신고 의무 | 원상복구 비용 청구 + 경고 | 관리사무소 |

## 누적 경고 제도

| 경고 횟수 | 조치 |
|-----------|------|
| 1회 | 서면 경고 발행 |
| 2회 | 1일 공사 중지 |
| 3회 | 공사 중지 및 건물 출입 제한 검토 |

> 경고 기산 기간: 공사 기간 전체

---

## 경고 이의 제기

공사업자가 경고 처분에 이의가 있는 경우:
1. 경고 수령 후 5영업일 이내 이의 제기서 제출
2. 이의 제기 기한: 관리사무소 또는 건물주에게 서면 제출
3. 검토 후 7영업일 이내 결과 통보
