## 적용 시점/트리거
모든 공사 작업, 원상복구, 폐기물 반출이 완료된 후 건물 반출을 위한 최종 절차입니다.

---

## 전제조건
- 모든 공사 작업 완료
- 원상복구 완료 ([원상복구 기준](./restoration.md) 참고)
- 폐기물 전량 반출 완료 ([폐기물 처리](./waste-disposal.md) 참고)
- 보양재 전량 철거 완료

---

## 필요 입력물
- [ ] 공사 완료 신고서 (관리사무소 양식 또는 아래 내용 포함)
- [ ] 원상복구 체크리스트 (자체 작성)
- [ ] 폐기물 처리 확인서 (해당 시)
- [ ] 출입증 전량 (반납용)

---

## 절차

1. **자체 점검**: 원상복구 체크리스트를 작성하며 전 구역 자체 점검
2. **완료 신고서 작성**: 공사 완료 신고서에 공사 기간, 시공 내용, 자체 점검 결과 기재
3. **신고서 제출**: 관리사무소 방문 또는 포털 업로드로 제출
4. **검사 일정 협의**: 관리사무소와 현장 검사 일정 협의 (제출 후 영업일 기준 5영업일 이내)
5. **현장 검사**: 관리사무소 담당자 입회 하에 현장 검사 수행
6. **출입증 반납**: 검사 통과 후 출입증 전량 반납
7. **완료 확인서 수령**: 관리사무소로부터 공사 완료 확인서 수령

---

## 검사 통과 기준

| 항목 | 기준 |
|------|------|
| 원상복구 | 전 훼손 부위 복구 완료 (육안 기준) |
| 폐기물 | 공사 구역 및 공용 구역 잔여 폐기물 없음 |
| 보양재 | 전량 철거 및 반출 완료 |
| 공용 구역 | 공사 흔적 없음, 청결 상태 |
| 출입증 | 발급 수량과 반납 수량 일치 |

---

## 예외 및 결정 분기

| 상황 | 처리 방법 |
|------|-----------|
| 검사 불합격 | 불합격 항목 목록 수령 → [원상복구](./restoration.md) 재작업 → 재검사 신청 |
| 출입증 분실 | 분실 신고 및 분실 수수료 납부 후 완료 처리 |
| 공사 기간 내 미완료 | 공사 기간 연장 신청 (기간 만료 전 신청 필수) |
| 재검사 기한 초과 | 관리사무소에 사유 설명 및 연장 신청 |

---

## 반려 시 재신청 경로
완료 신고 반려 또는 검사 불합격:
1. 불합격 항목 목록 수령
2. 해당 항목 보완
3. 재검사 신청 (기한: 불합격 통지 후 7영업일 이내)
4. 재검사도 불합격 시 → 관리사무소 담당자와 직접 협의
